# Growth Analytics Case Study

This project turns two real-world growth analytics tasks into one portfolio-ready deliverable:

1. A marketing A/B test decision using conversion rate, statistical significance, lift, confidence intervals, and segment diagnostics.
2. A GA4 ecommerce funnel and retention readout using the Google Merchandise Store public BigQuery dataset.

## Problem

Growth teams need to decide whether acquisition campaigns and ecommerce experiences are improving user outcomes, not just producing more activity. This case study asks two practical questions:

- Did the marketing ad outperform the PSA control enough to ship?
- Where does the ecommerce journey lose the most users between product view and purchase?

## Method

For the A/B test, the analysis compares users in the `ad` and `psa` groups from the Kaggle marketing A/B testing dataset. It calculates conversion rates, runs a two-sided two-proportion z-test, estimates relative lift with a 95% confidence interval, and checks whether the effect is consistent by day of week and hour.

For the funnel and retention analysis, the SQL queries use `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`. The funnel counts unique users reaching `view_item`, `add_to_cart`, `begin_checkout`, and `purchase`, then quantifies drop-off at each stage. The retention query builds simple day-1 and day-7 cohorts from first observed activity.

## Finding

The final finding should be updated after running the datasets. The dashboard is designed to surface:

- The ad and control conversion rates.
- The statistical confidence behind the A/B test decision.
- The biggest ecommerce funnel leak.
- A stakeholder-friendly funnel chart and cohort retention curve.

## Recommendation

Use the recommendation generated by the dashboard as the memo headline:

- Ship if the ad has statistically significant positive lift and the segment view does not show the effect coming from one narrow outlier.
- Do not ship if the result is significantly negative or operationally too small to matter.
- Test longer if the confidence interval is wide, the result is not significant, or segment performance is unstable.

## Project Structure

```text
app/streamlit_app.py              Streamlit dashboard
scripts/run_ab_analysis.py        CLI analysis for the Kaggle A/B test
src/growth_analytics/             Reusable analysis helpers
sql/ga4_funnel.sql                BigQuery funnel query
sql/ga4_retention.sql             BigQuery retention query
data/raw/                         Local raw datasets, ignored by git
data/processed/                   Generated CSV outputs, ignored by git
```

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Run the A/B Test

1. Download the Kaggle Marketing A/B Testing dataset.
2. Save the CSV as `data/raw/marketing_AB.csv`.
3. Run:

```bash
python3 scripts/run_ab_analysis.py
```

This writes:

- `data/processed/ab_summary.csv`
- `data/processed/ab_by_day.csv`
- `data/processed/ab_by_hour.csv`
- `data/processed/ab_recommendation.txt`

## Run the GA4 Analysis

1. Open BigQuery.
2. Run `sql/ga4_funnel.sql` and export the result to `data/processed/ga4_funnel.csv`.
3. Run `sql/ga4_retention.sql` and export the result to `data/processed/ga4_retention.csv`.

The queries use the public Google Merchandise Store GA4 sample dataset, so no app instrumentation is required.

## Launch the Dashboard

```bash
streamlit run app/streamlit_app.py
```

The dashboard also supports uploading the Kaggle CSV directly from the A/B test tab.

## Portfolio Framing

This project is intended to read like a growth analyst case study, not a notebook dump:

- Problem: Should we ship the marketing ad, and where is the ecommerce funnel leaking?
- Method: A/B test statistics, segment diagnostics, GA4 funnel SQL, and cohort retention.
- Finding: Quantified lift, confidence interval, biggest leak point, and retention behavior.
- Recommendation: A clear ship, do-not-ship, or test-longer decision.
